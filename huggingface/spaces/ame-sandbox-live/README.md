# Artificial Mind Engine (AME) — Live Interactive Sandbox

Welcome to the official **Hugging Face Static Space** for **Artificial Mind Engine (`MIT` Open Interface & Contract Sandbox)**, connected live via CORS (`https://thesoulthread.com/ame-demo`) with zero API key and zero cold-start delay.

> **"LLMs are swappable stateless CPUs; Artificial Mind Engine is the proprietary stateful cognitive OS kernel responsible for persistence, adaptability, and emotional coherence."**

## What You Can Test Here (Zero API Key Required)

This Space renders the interactive **MIT Open Interface Console** (`packages/sandbox-server/src/demo-ui.html`) backed by the live public OpenAPI 3.1 contract sandbox (`https://thesoulthread.com/ame-demo`). You can also self-host locally via `deploy/Dockerfile.sandbox`:

1. **Pre-populated 1-Click Scenario Presets** — test deterministic cognitive invariants immediately:
   - **D3 Atomic Erasure (`0.00%` Leak)**: Seed a private secret, verify recall, issue `DELETE /v1/minds/{mindId}/memories/{memoryId}`, and verify `0.00%` residual leakage + KV epoch bump.
   - **HOT Type-2 Abstention (`FAR 0%`)**: Test unverifiable medical/future predictions vs. grounded recall.
   - **FEP Conflict Deliberation Lock**: Contrast conflict/high free-energy turns (`locked: true`, `<thought>` lock) against calm turns (`locked: false`).
   - **D2 Offline Homeostasis**: Step `idle-tick` (`0h -> 48h -> 168h`) and inspect neutral absence framing + free-energy relaxation.
   - **D4 Unconscious Telemetry Isolation**: Verify forbidden internal affective/endocrine vectors are never exposed in responses or telemetry.
2. **Domain Profiles**: `companion_chat`, `game_npc`, `counseling_coach`, and `custom`.
3. **Full OpenAPI 3.1 Explorer**: Inspect schemas (`spec/openapi.yaml`) across `/v1/minds`, `/prepare`, `/settle`, `/turn`, `/idle-tick`, `/memories/{id}`, `/telemetry`, and `/simulate-batch`.

## Provenance & Scope Disclosure

- **Sandbox Contract vs. Sealed Production Kernel**: This Space runs the **MIT Open Interface Sandbox (`sandbox-contract`)**, implementing the exact OpenAPI 3.1 schemas, KV prefix framing, D2/D3/D4 contracts, and interactive UI flows for zero-cost exploration. Proprietary 5-layer closed-form equations and `pgvector` HNSW + Jina `v3`/`Reranker v2` live weights remain inside `ame-kernel-sealed:v4.3.0`.
- **Evidence Tier Separation (`AACIM v2.5.2`)**: Software architecture constants and telemetry contracts here are engineering specifications (`[공학·E4]`); Tier-1 live LLM benchmarks are reported in [`artificial-mind/ame-benchmarks`](https://huggingface.co/spaces/artificial-mind/ame-benchmarks) and [`artificial-mind/ame-eval-traces`](https://huggingface.co/datasets/artificial-mind/ame-eval-traces); human psychological hypotheses (such as `P9` reflection-to-attention feedback) are tracked separately as unverified research proposals (`[가정·E4]`).
