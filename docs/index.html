06 · 1-Minute Quickstart

1-Minute Quickstart: From Zero-Key Local Sandbox to Sealed Kernel Deployment

Run the OpenAPI 3.1 contract and multi-domain adapters immediately via packages/sandbox-server without any external LLM API key.

1. Run Local Contract Sandbox (Zero-Key · :8090) 
git clone https://github.com/bearrhee/artificial-mind-engine.git
cd artificial-mind-engine
npm run sandbox
curl -s http://127.0.0.1:8090/v1/health
2. Multi-Domain Adapter Demos (3 Domains) 
npm run example:game
npm run example:chat
npm run example:counseling
3. CogEval · LoCoMo Verification Harness & SDK Tests 
npm run bench:smoke
npm test
4. Connect Sealed Kernel Container (Commercial / Eval License) 
docker pull ghcr.io/bearrhee/ame-kernel-sealed:latest
docker run -d -p 8090:8090 -e AME_API_KEY="your-key" ghcr.io/bearrhee/ame-kernel-sealed:latest
curl -H "X-AME-API-Key: your-key" http://127.0.0.1:8090/v1/health
