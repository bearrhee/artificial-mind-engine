Artificial Mind Engine (AME)

“LLM은 교체 가능한 CPU, Mind Engine은 비공개 상태유지 인지 운영체제”

AME는 무상태(Stateless) LLM 위에 영속적 인지 커널(AACIM-59 · Panksepp 7 · FEP Selective Lock · GWT · HOT)과 4-경로 하이브리드 장기 기억을 분리 탑재합니다. OpenAPI 3.1 계약만으로 Claude, GPT, Gemini, DeepSeek, 로컬 vLLM/Ollama를 핫스왑하면서 반사실 인과(D1), 유휴 항상성(D2), 3중 원자적 기억 파기(D3), 무의식 비누설(D4)을 코드 불변식으로 강제합니다.

01 · Open Interface / Closed Kernel Architecture

개방형 인터페이스(MIT)와 비공개 인지 커널(ame-kernel)의 물리적 분리

SDK, LLM 어댑터, 도메인 앱, 로컬 샌드박스, 검증 하네스는 MIT로 완전 공개해 개발자 표준을 형성하고, 핵심 상태 동역학(AACIM-59 · FEP Lock · 3-Tier RAG · D3/D4)은 봉인된 커널 경계 너머에 보호합니다. 다이어그램 노드를 클릭해 계약을 확인하세요.

06 · 1-Minute Quickstart

1분 퀵스타트: 제로-키 로컬 샌드박스부터 봉인 커널 배포까지

외부 LLM API 키 없이도 packages/sandbox-server로 OpenAPI 3.1 계약과 멀티 도메인 어댑터를 즉시 실행할 수 있습니다.

1. 로컬 계약 샌드박스 실행 (Zero-Key · :8090) 
git clone https://github.com/bearrhee/artificial-mind-engine.git
cd artificial-mind-engine
npm run sandbox
curl -s http://127.0.0.1:8090/v1/health
2. 멀티 도메인 어댑터 데모 (3 Domains) 
npm run example:game
npm run example:chat
npm run example:counseling
3. CogEval · LoCoMo 검증 하네스 & SDK 테스트 
npm run bench:smoke
npm test
4. 봉인 커널 컨테이너 연결 (Commercial / Eval License) 
docker pull ghcr.io/bearrhee/ame-kernel-sealed:latest
docker run -d -p 8090:8090 -e AME_API_KEY="your-key" ghcr.io/bearrhee/ame-kernel-sealed:latest
curl -H "X-AME-API-Key: your-key" http://127.0.0.1:8090/v1/health
